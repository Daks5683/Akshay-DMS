# Akshay DMS

A live, cross-platform two-wheeler dealership management system for inventory, customers, sales, service work, staff roles, and reports.

> Initial scaffold. This repository will contain web, mobile, desktop, and CLI applications sharing the same API and database.

## Planned applications

- `apps/web`: Next.js web application
- `apps/mobile`: Expo / React Native application
- `apps/desktop`: Tauri desktop application
- `apps/cli`: Node.js command-line application
- `packages/shared`: shared types and validation
- `packages/api`: shared backend/API contracts

## Planned features

- Two-wheeler inventory and stock reservations
- Customer profiles and purchase history
- Quotations, sales, invoices, and deliveries
- Service appointments and job cards
- Role-based staff access
- Live updates across connected applications
- Dashboard reports and exports

## Development

```bash
npm install
npm run dev
```
